A document is the source of truth, and the tooling reads it. 95

There is no database beside the documents and no index derived from them that anything trusts. A type is declared by a <template> in a document, an instance claims that type with an attribute on the element making the claim, and a command or an audit is a script inside the document that owns the vocabulary it touches.

The cost is real and paid on purpose: reading the corpus means parsing every file, and nothing can answer a question the markup does not already hold.
