Where a family keeps its files is the family's own business, and the engine computes nothing about it.

Each family decides where its files sit and how a path to one gets built. The language family splits terms, rules and guides into directories; the knowledge family keeps one flat directory of dated files. The engine computes nothing about either.

A path rule in the engine would have to know every family's layout, which is the same second copy this project refuses everywhere else. It would also decide for a family nobody has designed yet.

What follows is small and easy to get wrong by hand. An edge from a term to a guide has to climb out of the directory holding the term, and an edge to a template keeps the leading dot-dot that reaches it. The family resolves its own path before asking for the href.
