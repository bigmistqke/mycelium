Editing generated code is annotation, but decoding intent from a diff is what we must avoid

Imported from the project’s earlier decision log, frozen 2026-07-23.

A user editing the WAT is like annotating on the whiteboard: intent expressed through a surface that is not the graph. The system then has to infer that intent from a diff.

Risk of misinterpretation. Decoding intent from code is exactly what we are trying to avoid.

 the risk of misreading a diff forces an explicit menu of ways to handle code edits
