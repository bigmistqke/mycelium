Every "the agent must remember to X" in the design is now a defect

Imported from the project’s earlier decision log, frozen 2026-07-23, the consequence of the harness reframe.

Each instance of "the agent must remember to X" gets inverted:

  • Claude must log decisions → the harness logs, extracting from claude -p output.
  • Claude must cite the commit → the harness writes the commit. The hook becomes a backstop rather than the mechanism.
  • Claude must maintain the graph → the graph is a side effect of the protocol running.

The gates stop being checks on Claude's homework and become steps in a pipeline that produces the artifact as it goes.

 the consequence: each remember-to becomes a defect
