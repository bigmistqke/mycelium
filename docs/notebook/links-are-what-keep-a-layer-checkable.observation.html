A layer stays checkable only while it carries links back to the artefact

What caught the error was opening the source file. The ground sat three commands away the whole time.

The readings each gave commit hashes. The scorer quoted the records. My report gave neither, and that is where the mistake stopped being checkable.

So the layer that drops its links is where an error turns permanent. Everything above it inherits the error with no way back to the thing that would settle it.

This is the hyperlinked part of the graph doing real work rather than decorating. A node carrying its evidence lets anyone re-check it later. A node stating a bare claim gives a reader nothing to pull on.

The hollow-action audit in knowledge.template.html already enforces a weak form of this, since an action has to carry a detail or a commit.
