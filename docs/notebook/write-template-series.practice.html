Eight commits across one session, which is why this node deliberately carries no knowledge-commit — CLAUDE.md cites it as the worked example of that rule:

  • 1628d92 — add a template for design specs, and write one
  • 3766d2e — rework the spec template to hold named sections, adopt the file-naming convention
  • 3286838 — move conforms-to from a head link to an element attribute
  • bec9aae — hyphenate every invented tag, prefix by family
  • 5f643b6 — split shared CSS into stylesheets, write down field-vs-link
  • 08e555b — rename the graph-* tag family to knowledge-*
  • a01a379 — build knowledge.template.html, deciduous's six node types as templates
  • fe57b12 — collocate the graph-wide audits, derive their input from real markup

The sequence is a series of corrections rather than a build: each commit overturns a choice made in the one before it. Sections replaced a header, attributes replaced a head link, hyphenated names replaced colliding ones, and collocated audits replaced a separate audits file.

Spans several commits, not one — the design spec itself, the header-vs-sections correction, data-conforms-to, hyphenated family-prefixed tags, the shared stylesheets, and finally knowledge.template.html with its collocated audits. knowledge-commit/knowledge-files are omitted rather than pointing at just one of them.
