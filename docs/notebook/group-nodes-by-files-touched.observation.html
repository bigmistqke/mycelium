Group nodes by the files they touch, and cluster those files into modules

Action and outcome nodes already carry an optional files field. The proposal was to use it as a join key: group nodes by the files they touch, cluster those files by directory into modules, and read the decisions behind each cluster as that module's rationale.

Rejected. File clustering tells you what changes together, which is code organisation. Architecture sits above that. A join on paths can only ever reproduce the directory tree, which is already visible for free.
