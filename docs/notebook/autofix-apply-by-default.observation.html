Autofix applies a verified fix by default; --diff previews it instead

Adopts the apply-mode option as proposed, and only that option. Every other command in this CLI writes in place with no confirmation step, so autofix follows the same convention: it applies a fix once that fix passes the violated rule's own check, and a session that wants to see the rewrite first passes --diff, which prints the proposed change without writing it.

The CLI-routing option stays open. Whether a fix inside an actual corpus document goes through that family's own update command, or every fix is a raw file write regardless of target, waits for a follow-up decision.
