knowledge generate graph already draws its family, so the shape of the command exists. The canon chain differs in one way that matters: it has fixed layers. An axiom narrows an axiom, a behaviour refines an axiom, a case checks a behaviour, and a specification names the files it answers for. That is a ranked graph rather than a mesh, so it wants a layered drawing rather than a force layout.

What it should make visible is the thing no check reports. grounded says an axiom reaches a behaviour; it never says how far or how much. An axiom carrying one behaviour and an axiom carrying twelve pass identically, and the difference is exactly what a reader wants when deciding whether a principle is load-bearing or merely vague.

The same reading gives a blast radius. Rewording an axiom means re-deriving everything beneath it, and today that list has to be assembled by hand from edges pointing the other way.
