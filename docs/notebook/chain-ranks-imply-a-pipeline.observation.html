The chain draws four ranks in sequence, but implementation and test cases are siblings under behaviour

The chain page lays out axioms, behaviours, test cases and implementation as four columns left to right, and canon.template.html's own prose says The chain runs axiom, then behaviour, then test, then implementation. That sentence describes a pipeline.

No edge runs from a case to a declaration, in either direction, and none ever did. the axiom that stores only upward edges enumerates three: a behaviour names its axiom, an axiom names the one it narrows, a test names the behaviour it checks. A code citation is a fourth, and it is a second child of behaviour rather than a child of test.

The layout shows the mismatch. Every wire out of the implementation column runs back over the test-case column to reach a behaviour two columns away, and nothing on the page explains the skip.

Neither edge is wrong. A declaration does not answer to a test — both answer to the claim — and a case and a declaration sit at the same height, so an edge between them has no up.
