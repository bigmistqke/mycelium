Extend autofix to corpus HTML leaf-block paragraphs

Adds a third AutofixItem kind, html, alongside comment and markdown. Region-finding for .html files now walks document.body for BLOCK_TAGS leaf elements. It finds only elements with no BLOCK_TAGS descendant and no PROTECTED_TAGS ancestor. For each, it locates the exact source range by searching for its serialized outerHTML with an advancing cursor, using the same technique that the <script>-range search already used, applied to a leaf element instead of a script.

The model sees the element's raw innerHTML (tags preserved, told to keep them exact) and the rewrite is spliced back between the original opening and closing tags, mirroring the markdown path's leading/core/trailing split.

Verification wraps the rewrite back in its own tag (li in a ul, td/th in a table/tr, everything else standalone) and requires no BLOCK_TAGS descendant survive, before running the same stripProtected + extractProse + rule.check() pipeline every other kind already uses.
