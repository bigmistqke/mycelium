Deciduous's node types are IBIS with the argument type removed

IBIS (Rittel & Kunz, 1970s) uses three node types: issue, position, argument. A position answers an issue; an argument supports or opposes a position. gIBIS (Conklin & Begeman, 1988) made it hypertext; Compendium is its descendant.

Deciduous's goal/decision/option maps onto issue/position. The type whose entire job is to support or oppose has no counterpart — and the graph's measured gaps are exactly where it would sit: contradicts 0, option 0, no node type carries evidence for or against a claim.

Shipman & McCall's split is the other useful borrowing, because it matches the story-versus-database tension directly. Documentation perspective: outsiders understand what was decided, only results and immediate explanations needed. Argumentation perspective: the logical structure must be explicit so the system can do the bookkeeping and detect errors. They cost differently, and which one you want decides the vocabulary.

Source: The what and whence of issue-based information systems.
