An id surviving a reword is what leaves a changed behaviour silently cited

A stable id means a copy-edit never breaks a citation, which is the property worth having. It also means someone can change what a behaviour says while every citation to it still resolves, so nothing tells the citing tests they now check something the document no longer claims.

The rename case is covered and this one is not. Renaming an id fails every citation, so a rename becomes deliberate. Rewording in place passes every check in the design.

This is the failure the earlier project started from. An axiom got re-described for a genuine reason, and in the same edit an example expanded into a phrase contradicting a rule two sections later, which a person reading the result caught rather than any check.

That project left the same question undecided: whether an edit should fail the check until each citer confirms it still derives, through some stamp recording the version it read. The stamp is stronger and more annoying, and reporting the reach alone rests on the discipline that failed in the first place.

 the gap a stable id leaves, which no audit in this design closes
