A model may sit wherever a number grades it, which bounds its scope better than its size does

A small model can sit inside the chain, and the useful limit on it is not its size. The limit is whether something that needs no model scores what it produced. Propose a placement and the count of overlapping boxes judges it. Propose a column and the count of crossing edges judges it.

Under that rule a model never wins by sounding right, because it does not decide anything. It offers a candidate and a number ranks it against the others. This keeps the property that makes a command worth asking before a person, one level further down.

The rule also names where no model belongs. Whether an axiom reaches a behaviour carries no number, only a reading, and a reading from a model is the flattery the command avoids. grounded walks the graph for that reason and should keep walking it.

One caution comes with the idea. Placing boxes to avoid each other is a search, and search has solvers that predate models and beat them on cost. A number that can grade a candidate can usually drive annealing straight, so the grading is the part to build first either way.
