Mycelium as the harness, not a tool the harness drives, is the automation side of an unsettled argument

right now mycelium is a tool that claude uses and we can introduce hooks/skills to try to reenforce it -> i wonder if mycelium could at some point become the harness instead: becomes the interface between llm and human, or maybe even chain-of-thought becoming the knowledge-graph

Mycelium is a tool an agent is asked to use, and every mechanism for making that happen sits outside it: a hook, a skill, prose in CLAUDE.md. The question is whether it could be the harness instead, so capture is not a separate act that can be skipped.

This lands on an edge the graph already marks as contested

Automation kills the maintenance burden and capture cost is what killed prior rationale systems contradict each other, and have since January with no outcome on either. This is the strong form of the first: not sync between two representations, but no second representation at all.

What argues for it

Every failure on 2026-07-31 was the harness deciding what got done, which is the claim the harness manufactures the clutter already makes. unlink existed and was invisible, so a session rebuilt a node instead of using it. The command list in CLAUDE.md went stale twice in one day. Someone wrote a dictionary rule that duplicated an audit already gating the build. Logging happened three times only after a person asked for it.

Two things the strong form has to answer

Chain of thought is not a decision graph. It is exploratory, repetitive and mostly wrong on the way to being right. The session that prompted this produced roughly twenty-five nodes from a great deal of reasoning, and the discarding is where the value was.

A node carries a claim, not an incident, and raw reasoning is all incident. Transcribing it reproduces what made the earlier log unusable, which is why the import rule kept 60 nodes of 400.

So the question is not whether capture can be free. It is what the derived layer looks like once it is. At zero capture cost, selection is the scarce thing and every design decision moves to the read path, which is the direction fix the read path first already chose.

A single system has nothing outside it to catch its own bias. Today's distortions were visible because two systems disagreed: the command list against the tool, a dictionary rule against an audit. Something that is both the harness and the record loses that, and the claim it would be losing it against is precisely that the bias is large.
