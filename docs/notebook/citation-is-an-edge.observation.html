A citation is an edge on a test case, not a tag in a comment

Two notations for the bottom rung. A comment carrying @specification above a leaf test, which is what another project running this methodology uses; or an ordinary depends_on edge on the test-case element itself.

The comment lost on three counts. A test here is already a document with an id, so the tag reproduced an addressing scheme the corpus had. Only a leaf test counts, and a leaf test in that notation is an it(...) call, which this project does not use anywhere. And a tag in a comment sits in text other parts of the system may reformat, which is how it failed twice: once by never seeing a test with no comment above it, and once when the prose view began dropping tag lines.

The edge costs nothing new. every-link-resolves already checks that a link reaches the anchor it names, depends_on is the relation every rung above already uses, and a case carrying an id means a violation names an address somebody can open rather than a slug made from wording.
