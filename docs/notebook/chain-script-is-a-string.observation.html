The chain page's script cannot be checked, because it is a string rather than a file

The page the chain command writes carries 163 lines of layout and selection logic, held as a template literal inside the command. Nothing reads it as code: no editor checks it, no citation can name a declaration in it, and no check can import it.

That blocks what the under-pane design rests on. A browser check runs against a fixture inside its own document, so it cannot navigate to a page the command wrote to a temporary file. The figure engine is checkable for exactly the opposite reason: it is a real file, and a check builds a small figure in its own fixture and lets the same code lay it out.

Extracting it costs one property worth keeping. The page is self-contained on purpose, so a reader can move the file and it still draws. A script loaded by src would end that.

Inlining the file's text at generate time keeps both. The code lives in a file that tooling and checks can reach, and the page still carries everything it needs.
