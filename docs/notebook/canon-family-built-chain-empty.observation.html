The canon family checks its own worked examples, and nothing else yet

The plan's four tasks all finished, and every step passes its own check. The template declares three types, the authoring commands write them, and grounded, exhaustive and cited run under mycelium validate with no engine change: the crawler found them because they carry the same attributes every other audit does.

Those three checks currently reach the template's own worked examples and nothing else. docs/canon/ does not exist. The corpus holds no axiom, no specification and no behaviour outside the samples, and this repository ships no tests and no test runner, so the citation reader finds zero citations in real source.

So each check demonstrably fires and demonstrably passes, which is the most a worked example can establish, and none of them has yet met a claim somebody meant. Each sample fails its own check on purpose and each check declares that failure in data-expects, so a check that stops working fails the build rather than going quiet.

What remains is the reading, not more tooling: writing the axioms this project actually holds, the specifications for the subsystems it has, and the tests that cite them. The design already names that as the cost, and says a broad axiom nobody has read down into a subsystem looks exactly like one that does not apply.
