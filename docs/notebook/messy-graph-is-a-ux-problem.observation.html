A messy graph is a UX problem, not inherent: fold, abstract, fade and clean it up

Imported from the project’s earlier decision log, frozen 2026-07-23.

Messy graph is a UX problem, not inherent. Mitigations:

  • hierarchical abstraction (subgraphs);
  • semantic folding (show relevant nodes only);
  • temporal layers (old decisions fade);
  • hybrid views (macro vs micro);
  • AI-driven cleanup.
 the graph half's complexity explosion is answered by folding, not by dropping the graph
