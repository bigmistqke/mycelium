An upload step told to ignore an empty match cannot report a stale path harness

The checks workflow uploads a failing browser case's screenshot as an artifact, and it named docs/tests/*.failure.png. The runner writes each picture beside the document that failed. Those cases moved into the canon documents, and the path went on matching nothing. Setting if-no-files-found to ignore swallowed the difference, so the step went green on a red run while returning nothing.

Ignoring an empty match suits the case it exists for, since most red runs fail on typecheck or validate and draw no picture at all. It cannot tell that case apart from a path pointing at a directory nobody has written to in weeks. A glob naming no directory removes the question, because docs/**/*.failure.png follows the documents wherever they land.
