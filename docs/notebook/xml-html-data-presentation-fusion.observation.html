This project's documents collapse XML's data/presentation split back into one file

XML historically split data from presentation. This project's documents collapse that split back into a single file: one document is simultaneously

  • queryable structured data, via data-conforms-to and custom elements, and
  • its own default rendering,

with nothing else required.

 the fusion of data and presentation into one file is the deeper reason HTML beat DB + Markdown, not just a stated preference for querySelector convenience
