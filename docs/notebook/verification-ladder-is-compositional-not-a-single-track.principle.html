The verification ladder is compositional: real systems layer it across slices, not pick one rung

Example-based tests, property-based tests, model checking, and theorem proving trade a widening guarantee for a narrowing scope of property they can even attempt:

  • example-based tests — one input;
  • property-based tests — a large random sample;
  • model checking — an exhaustive-but-abstracted model;
  • theorem proving — total certainty over the real code.

A real system layers them across different slices rather than picking one.

Mutation testing sits on a different axis entirely: it checks that existing tests are sensitive to injected bugs, rather than proving any property true.
