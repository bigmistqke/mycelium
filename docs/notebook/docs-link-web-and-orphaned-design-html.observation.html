docs/ is already a multi-kind link web, but DESIGN.html sits outside it entirely

docs/ is already a small, self-contained link web with cheap backlinks, and it is multi-kind — three different sorts of link already run through it:

  • data-rel edges
  • data-conforms-to
  • spec inline cross-refs

DESIGN.html, by contrast, has zero outbound links and sits outside that web entirely.

 the existing link web is already multi-kind and cheap to traverse, which is what makes a reading-mode canvas viable
