Two of twenty citations pointed at the wrong node, and one error propagated

Computing the import closure meant reading every node in the earlier log that the v4 graph cites. Twenty distinct citations; two were wrong, both in declare belonging, derive liveness:

  • "the missing retirement concept" pointed at an option about which language to implement in. The retirement concept is the note on permanently-pending decisions.
  • "Composition makes decision status DERIVED, not declared" was attributed to a note about two abstraction ladders being the same structure. The quoted sentence is verbatim from the note on derived status.

Both claims were sound; only the pointers were wrong. That is what makes this the expensive kind.

Any link checker catches a citation to a node that does not exist. A citation to a real node that does not support the claim reads as fine and survives every structural check — exactly the case that node argues needs mutation testing or blind re-derivation. Blind re-derivation found it: reading the target and asking whether it says what the citing node claims.

The error propagated. Two later nodes inherited it without re-checking.

The retired-status-enum option repeated the first one. Link, do not tag, written hours later, repeated the second — describing the wrong pointer rather than going to the source. A citation copied from a citing node rather than from the source carries the original error forward and adds a witness for it.

Rate, with the caveat that it is one sample. 2 of 20 is 10%, and both sit in one node written in a single burst, so this is not evidence about citation accuracy in general — it is evidence that unverified citations in this graph are wrong at a rate above zero, which was previously unmeasured and assumed to be zero. The same discipline that produced the 52% caveat applies here: do not promote this number.

What it argues for. The import is the first thing that ever forced every citation to be resolved, and it found these immediately. That is a reason to finish it rather than a reason to be careful about it: a citation pointing into a corpus the graph cannot reach is a claim nobody can check.
