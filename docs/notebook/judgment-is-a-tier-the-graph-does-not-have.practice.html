Confidence conflates how sure a claim is with who is being sure, so judgement has no home

Every node in this graph is asserted flat. The confidence field carries one number, and that number mixes two unrelated things: how sure the claim is, and who is doing the being-sure.

There is no way to say that a model proposed a claim and nobody has confirmed it. That is exactly the state every derived node would arrive in, and it is the state the noise problem lives in. The graph already records that reverse-engineering intent from code is noisy. Judgement is what answers that, and there is currently nowhere to put it.

This is an observation about the system as it stands, not about the hypothetical one, which makes it the most immediately actionable thing this session produced.
