Link, do not tag: an imported node must connect to current material to come in

Drops the topic-tag half of declare belonging, derive liveness. The liveness half stands unchanged. Prompted by a concrete worry about the deciduous import: roughly 130 nodes of v0/v1/v2 implementation history landing in a graph about HTML templates.

Three problems with tags.

  • The date already encodes the chapter. Every file is date-prefixed and the chapters are date ranges — v0 is 2026-01-12 to 01-14, the vision work 01-24 to 01-25, the verify gate 07-13 to 07-15, v4 07-23 onward. A v0 tag restates the filename as a second copy maintained by hand.
  • Multi-membership is already an edge. The tag was justified by v0's query-interface decision belonging both to v0 and to the v3 synthesis leaning on it — but the cache-of-comprehension decision already writes that down, citing the query-interface decision. Where a thing was decided is one value; what leans on it is the edge set. A tag conflates them and then duplicates the second one worse.
  • The decision contradicted itself. It cites derived status, not declared and derive, do not curate — don't store it, derive it from the layer below, because it is derived it can be RECOMPUTED, which means IT CANNOT ROT — and then declares belonging as hand-maintained metadata. Liveness already uses a node with edges. Belonging was the only facet reaching for a new primitive. (This bullet cited a wrong pointer until 2026-07-30, inherited from the node it describes; the quoted sentence is derived status, not declared.)

What replaces it, and it is not a filter. The clutter worry is really that 130 nodes would sit in the graph doing nothing; tags would have hidden them without making them worth having. So the import rule becomes a requirement instead: a node comes in only if it can be linked to material that is already here. Relevance stops being a per-node judgment and becomes a property of the topology.

Under that rule the query-interface decision arrives because the cache-of-comprehension decision cites it, and the package-manager decision does not, because nothing refers to it and nothing would. Most of the v0 implementation history fails to link and therefore never arrives, so the clutter does not exist and nothing needs hiding.

This is already the standard elsewhere. orphans-except-goal holds that root goals are the only valid orphans, and the prior art agrees from two directions: Doyle's TMS, where a belief with no valid justification is simply out, and Dung's argumentation frameworks, where an argument that neither attacks nor is attacked is trivially accepted and therefore uninteresting.

Honest cost. Import gets more expensive per node, because each one needs a link decision rather than a tag stamp. That is the same capture-cost bargain as everywhere else here, with the difference that this one pays once and leaves a connected graph instead of a dumped one. Chapters may still be worth having later for reading the history as narrative — if so, a chapter node with membership edges, not a tag vocabulary.
