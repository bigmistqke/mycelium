Mycelium is an agentic harness, not a tool Claude has to remember to use

Imported from the project’s earlier decision log, frozen 2026-07-23.

The inversion. Old model: Claude is the agent, mycelium is a tool it must remember to use. New model: mycelium is the agent, and claude -p is a function it calls.

Fewer tools requiring LLM discipline; more protocols followed deterministically, with LLMs sprinkled in via claude -p where judgment is actually needed.

It runs standalone — CI, cron, unattended — and is callable from Claude Code. The second is a bonus, not the premise. A design that only works inside an interactive session is a design that depends on someone being there.
