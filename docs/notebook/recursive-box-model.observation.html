Recursive box model: the same node structure at every zoom level, no separate kinds

Imported from the project’s earlier decision log, frozen 2026-07-23.

A Russian-doll structure: the same shape repeats at every zoom level. A node has ports, children, edges and constraints.

  • A leaf is a function.
  • A node with children is a module.
  • The graph itself is the root node.

Because the structure recurses, no separate node kinds are needed.

 the same structure repeating at every zoom level is what lets one graph span every resolution
