  1. converse — describe intent;
  2. synthesize — the LLM adds constraints to the graph;
  3. visualize — explore macro, micro, dataflow;
  4. annotate — draw on the canvas;
  5. persist — chat to the decision log, state to git;
  6. time travel;
  7. iterate.
