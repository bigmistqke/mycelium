Generated code must round-trip: an edit to the output has to find its way back into the graph

Imported from the project’s earlier decision log, frozen 2026-07-23.

The roundtrip is Graph → WAT → Graph'. If the user edits the emitted WAT, how does that edit update the graph?

  • Metadata — edges, constraints — should not clutter the WAT output.
  • The user should not have to maintain that metadata manually.
 asking how an edit gets back into the graph reframes the edit itself as an annotation
