A citation is judged on where it lands, never on the tag that carries it

An audit reading citations has to resolve the fragment and ask what kind of thing sits at the other end. Reading the tag name is not the same check, because a citation carrying the right tag can still reach past a layer.

The project that ran this methodology before checked the tag and let sixteen citations through. Each named a test reaching straight to an axiom because the specification held no addressable behaviour for what the test asserted. All sixteen turned out to be real gaps, and three new rules got written to fill them.

So a test citing an axiom is a finding rather than a shortcut, and it is exactly the upward-travelling kind: the test knows something no specification states. Catching it needs the resolved target, since a tag dedicated to axioms and a general tag pointing at an axiom say the same thing.
