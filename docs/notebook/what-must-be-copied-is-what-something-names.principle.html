What a project must hold a copy of is whatever its own documents name corpus distribution

An instance names its own template by relative path, and every-link-resolves opens that path on every run. So a template has to sit in the same committed tree as the entries conforming to it. Point one at a package directory instead and the corpus stops resolving the moment somebody clones without installing.

Nothing ever names a command host. No document points at validate.command.html, because the engine resolves a host by id at run time from the identifier somebody typed. A command can therefore live anywhere the engine can reach, and a copy of one buys nothing but drift.

The rule generalises past this split. Whether a thing must be copied is not a question about what it is, and asking whether a template feels more essential than a command answers nothing. Ask instead what points at it, and whether that pointer has to keep resolving.
