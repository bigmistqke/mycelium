Verification only reaches properties that have a crisp, closed truth condition

Type- and proof-based verification only reaches where a property has a crisp, closed truth condition to begin with. Outside that boundary it

  • cannot check aesthetic judgment or "the right axiom";
  • cannot verify claims about the external world (sensor accuracy, network truth) beyond the shape of the data;
  • cannot help when formally specifying the property is as much work as building it;
  • cannot certify statistical or approximate systems, where there is no proof of "good", only evidence.
 sharpens why formal claims relocate the trust gap rather than removing it: some properties have no crisp truth condition to formalize at all within that boundary, elaborates the actual toolkit and how it composes
