Reaching for a measurement invents a failure that declaring the same thing cannot have

A label chip in the figure family came from an SVG rectangle sized by getBBox. That call ran while the overlay was still detached, where it answers zero, so every chip was twelve pixels by six in a corner.

Nothing threw and nothing failed a check. Two commits reasoned about paint order over a rectangle that had never had a size, and a reader looking at the page saw no change from either.

Replacing it with an ordinary element removed the measurement rather than fixing it. The graph is a positioned ancestor, a half-size translate centres a chip whatever its width, and the browser sizes the box it already knows how to size.

The general shape: code that asks for a number has a state where the number is wrong, and code that declares a relationship does not. This is the same argument the diagram itself makes about coordinates, one layer further in.
