What the graph keeps is the thinking a session cannot act on yet. Prior art somebody read, a direction nobody can build toward this month, a rule noticed but not yet checkable, a remark about how the work itself goes. None of it closes, and none of it wants a status.

This is the loss the project exists to answer. A task leaves artefacts everywhere already, in git and in the code and in the passing checks, so nothing gets lost by not writing it down twice. The half-thought that guides the next month leaves nothing, and by Tuesday nobody can find it.

So the four categories worth keeping are principle, reference, vision and method, which is 267 of the current 574. Build records go, because git holds them. Measurements and bug notes go, because a check recomputes what a note remembers wrong.

A principle here is one nobody has promoted yet. It waits in the notebook until a check can hold it, moves into the canon as an axiom, and the dated node stays behind as the record of when the thought arrived. That promotion is the forward edge the two graphs have never had, and a check going red is the edge back.

One question stays open: whether a goal belongs. A prompt is where intent enters, and 41 goals carry one. Some of those prompts redirect the whole project and some ask for a header fix, and nothing here separates them.
