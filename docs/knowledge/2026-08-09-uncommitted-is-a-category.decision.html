An earlier draft made a declaration owe a citation and failed the ones without. Two declarations in the first file tagged showed why that overreaches. MODEL picks which model to ask and could pick another tomorrow, and Verdict declares a shape that promises nothing on its own.

Exempting them by kind hides them, and forcing a behaviour on them invents a promise nobody made. A test for the judge runs on this model goes red when somebody edits the line and never catches a mistake.

So the absence becomes a category rather than an error. The check counts what names a claim and what does not, and prints both. A typed language works the same way: any is legal, and the point is that it shows.

The ratio is what the design exists to move. Counting uncommitted code makes it visible, where a rule exempting it by kind would leave the same code invisible and the number flattering.
