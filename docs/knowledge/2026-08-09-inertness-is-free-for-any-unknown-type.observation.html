A browser executes a script only when it recognises the type as JavaScript. Every other string leaves the tag inert, so text/mycelium-test and any invented name behave identically at page load. The runner reaches the case afterwards and evaluates it itself.

That retires an argument. Naming a browser case mycelium/browser-test was going to keep the case inert, which sounded like a property the rename preserved, and the current spelling has it just as freely.

So the text/ prefix does exactly one job: it keeps a browser case out of mycelium/, where the loader hook would tell Node the source may hold TypeScript and tooling would read it the same way. A type annotation would then pass every check and fail only once a person opened the page.

The candidate that beats both invents no name at all. type="module" with a default export makes a browser case the same shape as a node case, at the cost of the browser running it at load, which an export-only module survives.
