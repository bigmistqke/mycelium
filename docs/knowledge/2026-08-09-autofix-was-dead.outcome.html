Asking what autofix promises turned up nothing: no behaviour named it and no case ran it. Writing the behaviour meant writing the case, and the case would not start. The command threw resolveTemplateRef is not defined on every input.

The commit that moved validate onto the engine's filesystem dropped that import and renamed the call inside runValidate to templateRefFor. One call site inside autofix kept the old name. Nothing ran it, so nothing said so, and CLAUDE.md went on telling people to use it for a day.

Two cases cover it now: fields sort into the order their template declares, and an edge and an embedded script keep their place. The second one matters because a repair tidying more than it was asked to is one people run once.
