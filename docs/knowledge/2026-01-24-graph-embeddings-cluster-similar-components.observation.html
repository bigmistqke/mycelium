Graph embeddings project nodes into vector space so similar components cluster 82

Imported from the project’s earlier decision log, frozen 2026-07-23.

Project nodes into an n-dimensional vector space, deriving the vector from a node’s structure, ports, constraints and neighborhood. Similar components then cluster together.

What that enables:

  • pattern detection
  • anti-pattern detection
  • abstraction candidates
  • semantic search
