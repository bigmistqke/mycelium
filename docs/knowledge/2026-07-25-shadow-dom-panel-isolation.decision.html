Use Shadow DOM on a new panel-wrapper custom element for per-panel style isolation between opened documents, instead of iframes 75 completed

Reasons: same-document DOM access lets the canvas call panel.shadowRoot.querySelector('a[data-rel]') and read its getBoundingClientRect() directly, which an iframe's separate context would not give as cleanly.

CSS custom properties still cross a shadow boundary, so panels stay themed consistently via the shared theme.css variables even while isolated. And every tag in this project is already deliberately hyphenated in anticipation of real Custom Elements behavior, per spec.template.html's own stated reasoning.

Loading a panel means fetching the real document, parsing it with DOMParser, taking .body.innerHTML, and resolving its relative stylesheet hrefs (../theme.css, ../templates/knowledge.template.css) against the source file's own URL before reinserting them into the shadow root. That is a load-time transform inside the canvas tool, not a change to the source file format.
