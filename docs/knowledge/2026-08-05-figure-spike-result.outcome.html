A figure vocabulary closes the failure mermaid cannot have, and trades pixel coordinates for grid ones 78

Three files: a template declaring figure-graph, figure-node and figure-edge, a stylesheet, and a classic script registering the element. The repl report now carries the same diagram twice, once as mermaid and once as a figure, for comparison.

The audit works and it is the result worth keeping. Renaming one edge target to a name no node carries failed the build with the file and the bad name. Mermaid cannot fail that way, because an unknown name invents a node and renders a diagram that reads correctly and says something untrue.

The audit also needed no wiring. It declares data-audits and appears in mycelium --help beside the other six, which is the protocol doing its job.

Against the design as written: the template claims coordinates are measured and never written, and data-at="3,1" is a written coordinate. Connectors are measured, placement is not. A real layout engine would remove that attribute, and until one exists this trades pixels for cells rather than removing the problem.

Nobody has seen it render. The markup validates and the script parses, and this repository holds no headless DOM that implements layout, so the drawing half rests on reading rather than on a run.
