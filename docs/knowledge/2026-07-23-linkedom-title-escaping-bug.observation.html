linkedom does not escape a title element when serializing outerHTML 90

.textContent stores the value correctly, but outerHTML serializes it unescaped. Verified by round-tripping a literal </title><script> sequence through it and watching it inject real markup.

Fixed in knowledge.template.html's add command by pre-escaping before assignment.

Scope of the bug: real custom elements such as knowledge-title do not have this gap. Only the RCDATA <title> element does, so the fix belongs at that one assignment rather than anywhere a title is handled.
