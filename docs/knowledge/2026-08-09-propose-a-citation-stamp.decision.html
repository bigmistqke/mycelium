A citation resolves for as long as its target exists, and says nothing about whether the two still agree. Both the citation design and the fold admit this from opposite ends: a tag naming a behaviour the code does not implement resolves fine, and rewording a claim keeps every citation to it resolving.

A digest of the cited declaration would close the code half. The tag carries it — @behaviour canon/comments.canon.html#a-cut-takes-its-whole-line@a1b2c3 — so the stamp sits in the file that changes, and a check reports every citation whose declaration moved since somebody last read the two together.

The reader already knows where a declaration starts and ends, which is what the pane uses to show a whole implementation rather than a sample, so the digest costs nothing new to compute.

The cost is the one that killed the rationale systems this project cites as prior art: a stamp somebody must re-confirm on every edit is friction, and friction gets routed around. A large declaration changes constantly, so its warning becomes noise and re-stamping without reading becomes the habit. That makes this worth building only alongside the decomposition it depends on.
