The built-in HTML grammar gives an unrecognized script type zero syntax scope 85

Read against the real grammar VS Code ships (extensions/html/syntaxes/html.tmLanguage.json), not guessed from behavior. A <script> tag's content only gets source.js when type is empty or a recognized JavaScript mime type, and only gets nested text.html.basic when type matches a template convention (text/x-handlebars, text/template, …). Anything else — including every mycelium/* type this project uses — falls to the grammar's last branch, which names the region source.unknown: no grammar is registered for that scope, so TextMate contributes nothing there.

That means every color visible in a mycelium/* block comes from the language server's semantic tokens, not from syntax highlighting — and the standard TypeScript semantic-token legend does not cover bare keywords. The result looks inconsistent rather than absent: identifiers like a type name or a destructured binding get colored, while import, export, function, and type (as a keyword) do not, because nothing is tokenizing them at all.
