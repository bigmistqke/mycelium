A template file can be semi-standalone, co-locating its own docs and implementation 75 the presentation-side consequence of the fusion: real rendering lets docs and implementation share one file

Because the presentation side of that fusion is real, renderable HTML rather than a separate templating layer, a template file can co-locate its own documentation and implementation and stay semi-standalone:

  • Readable and self-explanatory with zero runtime present.
  • Only fully operable — the CLI commands — once the runtime is there too.
