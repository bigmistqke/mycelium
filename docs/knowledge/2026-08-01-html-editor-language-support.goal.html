Two separate complaints, one goal.

The first is type errors. There is no tsconfig.json anywhere under experiments/v4, and typescript is not a dependency. An editor's TypeScript server therefore reads src/*.ts under its own defaults, which are not the ones this project actually runs under — Node 24 running .ts files directly, with .ts import specifiers.

The second is that nothing supports the embedded scripts at all. This project keeps its real code in <script type="mycelium/command"> and its siblings, mycelium/audit and mycelium/rule. An HTML language service only treats a script as JavaScript when its type is a recognized JavaScript type, so every one of those blocks is plain text to an editor: no highlighting, no completion, no diagnostics. That is 2,042 lines, against 1,065 in src/, so it is most of the code in the project.
