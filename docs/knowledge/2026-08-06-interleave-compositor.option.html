A compositor on the parent that lets placeholders interleave 60

A word on the parent placeholder — interleave, XML Schema's xs:all against its xs:sequence — saying its children may appear in any order relative to each other, and that a run need not be contiguous. Cardinality, pattern and enum would still apply per placeholder.

It belongs on the parent because it states a fact about a container's content model, which is what a compositor is in every schema language that has one.

Deferred, not rejected. The case for it is a figure that narrates its graph — a node, the edge leaving it, the node that edge arrives at — which strict sequence rejects. No document in the corpus does that: the figure in DESIGN.html is eight nodes then eight edges, the repl report's is twelve then thirteen, and every test fixture groups the same way. Grouping nodes before edges also reads better, so the constraint is one worth keeping until a real document argues otherwise.
