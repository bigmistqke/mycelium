Some past sessions hand-edited corpus documents directly instead of the CLI's own commands 55

Raised as the reason to prefer routing an autofix through the CLI: past sessions in this project have sometimes edited a document by hand (a direct file write, or a Python script) instead of using the family's own add/update commands, for reasons not identified here. That bypasses the same validation and reindentation the CLI path gives every other write, which is exactly what an autofix should not repeat at model-generated scale.
