Dataflow JSON is serialization, not an authoring format. The visual whiteboard is the authoring interface — draw nodes, wire connections, see data flow. JSON verbosity is irrelevant when you never write it by hand.

Precedent: spreadsheets, Unreal Blueprints, Max/MSP, circuit schematics.

Stack: Whiteboard (visual) → JSON (storage) → WAT (execution). A conversation layer assists with wiring.

 explains why the verbosity is tolerable when authoring: the whiteboard is the interface, JSON is only storage
