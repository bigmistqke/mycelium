The header did not survive it. A block sized to the viewport, so its rule stopped where the viewport stopped and the scrolled part of the page had nothing under it. It now sticks at the left edge and spans the viewport width, so it stays put while the graph moves beneath it.

The larger version stays undone on purpose.
