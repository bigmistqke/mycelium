Deferred: mycelium/lint as a protocol script type, run by the engine 65

A generic mycelium lint, with <script type="mycelium/lint"> alongside type="mycelium/command". Any family could then contribute rules, and the engine would find and run them the same way it finds commands and audits today.

This is the alternative to keeping lint out of the protocol, and it contradicts that decision's own test: it makes linting protocol by declaring it one.

Deferred rather than rejected, because the test is about today's shape and not a law. One family owns every language rule, and a protocol for one participant is a protocol with nothing to coordinate. The condition is a second family wanting to contribute rules — at that point a per-family script type is doing real work and the dictionary command is the thing in the way.
