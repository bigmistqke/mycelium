The rationale already exists and is only unaddressable 70

Every project emits a decision record already. It emits it as commit messages, pull request threads, review comments, issue discussions, incident write-ups, changelogs and the one chat thread where the decision actually happened. Someone already put the reasoning in words. It sits across a dozen systems and nothing can query it.

That changes what derivation is. It is not a model guessing at why someone built something. It is finding the places where a person already said why, and putting them in one addressable form.

Most of the work is moving text, with a reader good enough to recognise a decision when it sees one. The limit on this is everything nobody wrote down, which no amount of reading recovers.
