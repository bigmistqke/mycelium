Rejected. It borrowed a boundary from another project, where in-scope suites are listed explicitly and the unit that owes a citation is a test.

Exports are the wrong boundary here. figure.element.js exports nothing and answers twelve behaviours; comments.command.html exports two functions whose real claims sit in cutRange, verdictPrompt and isRosterDoc. The rule would have put five citations on one entry point and none on the code answering them.

It also pointed the obligation the wrong way. Coverage measured from the code asks which functions somebody remembered to tag; measured from the claim it asks whether anything implements what the canon promises.
