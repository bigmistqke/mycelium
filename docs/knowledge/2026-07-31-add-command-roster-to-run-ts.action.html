Add a cross-family command roster to run.ts and put it in the SessionStart hook 80 completed

A roster prints every command host's id and its exported commands, one line each with the first line of the command's own doc comment. Derived from the same <script type="mycelium/command"> the engine already reads and the same acorn pass --help already uses, so it cannot drift from what the CLI actually exports — which a hand-copied list in CLAUDE.md can and did.

Names come from a strict exports-only pass rather than reusing extractCommandDocs, which deliberately indexes non-exported top-level helpers too. That is harmless for --help, which filters its names against the loaded module's real exports, but the roster never loads the module — it reads the source only — so it has to do that filtering itself or it would advertise requireArgs as a command.

Wired into the SessionStart hook beside knowledge recover, so the roster is in context without anyone choosing to run it. This follows the project's own finding that a protocol beats discipline; a line in CLAUDE.md saying "run --help" would be prose, and prose is exactly what was skipped.
