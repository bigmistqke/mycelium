A hand-placed diagram stops being a document the moment its meaning lives in coordinates 84

The first architecture diagram for the repl report was inline markup with every box and arrow positioned by hand. It rendered well and cost three rounds of fixing collisions between labels and dividers.

The deeper cost is that nobody can read it back. Its structure lives in x and y numbers, so learning what it claims means re-deriving the layout rather than reading a list of nodes and edges.

Mermaid keeps the same picture as a document. Twelve lines name the nodes and the edges, a renderer decides the geometry, and changing a claim means editing a line rather than moving four rectangles.

This is the same argument this project makes about rationale that nothing can query, one level down. A picture is a rendering of a structure, and keeping only the rendering loses the structure.

One caveat against reading it too widely. A drawing whose whole point is spatial, such as a timeline laid out against real dates, holds information no node-and-edge list carries.
