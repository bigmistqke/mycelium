Link a term to the terms its meaning names 85 completed

We wrote thirty-one cross-references into language-meaning, so a definition naming another term reaches it. The code that checks one instance against the template it declares conformance to now carries three links, which is what a dictionary entry should look like.

language-meaning had to become a rich field for this. It held plain text, so writing a link into it would have escaped and displayed it as markup.

We wrote it by hand rather than deriving it, which is the opposite of what the family spec argues for term uses across the corpus. The scope is what makes the difference: thirty-five entries naming each other is a bounded set a person can read, and cross-referencing is what a dictionary is for. Deriving edges from three hundred documents is the case where hand-annotation becomes the capture cost that kills the thing.

We wrote one link and then removed it. drift is defined as two copies of the same information diverging, and information is an entry only because it replaces the abbreviation info. Linking there points a reader at a spelling rule when the sentence meant the ordinary word. Every other link either names a term of art or points a rejected word at its replacement.
