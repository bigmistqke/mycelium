Only a leaf test carries a citation, because a group is navigation 80

The unit owing a behaviour is the test that asserts something, not the block grouping several of them.

The earlier project tried the enclosing group first and found it wrong from both sides. An outer group spans a whole file and answers to no single behaviour, so annotating one means picking a child's target arbitrarily, which invents a link rather than recording one. An inner group restates a citation every child already carries.

This matters for counting. A citation on a group covers several assertions at once, so does a test exist for this behaviour stops having an answer, the same way a behaviour written as a paragraph rather than a sentence breaks the question from the other side.
