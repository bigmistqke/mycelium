A fan collapses two altitudes into one, so the chain stays a line 85

A fan was on the table: test and implementation both citing the spec rule above them, with the relation between the two derived through that shared parent rather than written down. It removes an edge that no checker can verify, which was the appeal.

It also puts test and implementation at the same depth. Cutting the graph at that depth then returns both, and the two altitudes furthest apart in practice — the behaviour someone can observe, and the mechanism that produces it — arrive as one layer. The depth-slice decision rests on a descent that loses exactly one level per step, and its own example counts four of them.

So the line holds: axiom, then spec rule, then test, then implementation. The edge that no citation can carry needs a different kind of evidence, not a different shape.
