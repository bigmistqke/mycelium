Every rule in the language today takes text and returns matches. Passive voice, sentence length, a bare number sign — each one decides from the string alone.

Whether a comment deserves to exist decides from the comment against the code under it, and no regular expression reads that. It needs a model, which puts it outside what a language-rule can hold.
