The mechanism already exists here, aimed elsewhere. The graph generator's overlay found that hyphenated tags plus a stylesheet render a full card with no component at all, over positions a layout engine computed.

Two things such a vocabulary would buy that neither current form can. A node is a real element, so it can hold a link, and a diagram box could point at the source file or the node arguing about it. And an edge naming its ends can face an audit, where a mistyped name in mermaid invents a node and renders a diagram that lies.

The question in the prompt is whether this wants real registered custom elements rather than the inert styled tags used so far. That is the escalation to settle: a registered element can resolve its own edges and draw its own connectors, and the spec that removed the shared runtime warns about machinery outgrowing what it carries.

The honest cheaper option to rule out first: mermaid takes theme variables and per-node classes, and its rendered output accepts ordinary CSS. That recovers much of the look for an afternoon rather than a family.
