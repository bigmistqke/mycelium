Formal claims relocate the trust problem one level down rather than removing it 60 reframes v4's ontology-freedom while looking for where formal rigor could live

Fully verifying that an implementation satisfies an axiom requires formal claims — invariants stated in a formal language over a defined state model. Those invariants can be checked in escalating cost and certainty:

  • property-based testing
  • model checking
  • theorem proving

But formalizing an axiom incorrectly reproduces the same citation-fidelity gap one level down, relocating the trust problem rather than removing it.
