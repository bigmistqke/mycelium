graph: the page every ranked-graph drawing shares

Reads one of this project's own files by name, relative to wherever this library itself sits. Read rather than embedded, so a page's code and styling stay files a person can open and an editor can check.

Where one of this project's own files sits, without reading it. A server watching for changes needs an absolute path to hand to node:fs.watch, and this is the same "where do the templates live" fact templateFile already answers.

Reads several of this project's own files, keeping each one's own name beside it — what graphPage needs to inline a list of scripts by name rather than by concatenating them into one.

Assembles the page a ranked graph draws itself into: a header carrying counts, a grid for the columns, a canvas for the wires, and a pane for whatever a reader selects. Every graph gets the same shell, because every graph gets the same drawing — what differs is the title, the counts and the data, and those arrive as arguments.
