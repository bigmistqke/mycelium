Logging is a protocol and spec-writing is discipline, and only the discipline lapsed

Eleven plans exist, the last dated 2026-07-30. Nineteen specs exist, the last dated 2026-08-01. The figure vocabulary began on 2026-08-05 and the test family followed it, and between them they are the largest body of design in the repository. Neither family produced a spec or a plan.

The practice did not skip this work so much as stop before it. Both families saw heavy use for a week. The harness-shape plan carries six tasks whose steps almost all hold a runnable plan-check, and mycelium plan check runs them.

The knowledge graph did not lapse, and the difference between the two says why. Logging is a protocol here: a hook prints the graph at every session start, and the instructions make a node a rule with triggers. Writing a spec is discipline. Nothing asks for one, nothing notices its absence, and one session added fifteen nodes while reaching for neither other family.

So a tool alone does not make a practice. spec add and plan add both work, and both went unused for a week by someone running the neighbouring commands hourly. What the graph has that they lack is not a better command. It is a hook and a rule.

The cost shows in the figure engine's label placement. It settled over five rounds of drawing a picture, looking at it and adjusting, and each round found a rule the round before had missed: labels off the boxes, then inside the figure, then clear of each other, then off other edges' drops. Those are four sentences. Deciding them first is what a spec is for.
