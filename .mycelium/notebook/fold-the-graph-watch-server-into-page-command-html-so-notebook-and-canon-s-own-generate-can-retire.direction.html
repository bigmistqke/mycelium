If notebook's own generate gets replaced by page generate notebook graph, that richer watch behavior goes away — a real UX regression for anyone actively watching the notebook graph while editing. -> remove notebook generate graph --watch -> or make the page's hmr smarter Chosen direction: make page's watch smarter rather than drop the capability. page.command.html's serve() gains a corpus-wide file watcher, the same primitive serveGraph already used for one directory, now widened to every directory holding a document. Once serve() does both, notebook's own generate graph --watch and canon's missing watch both fold onto page generate --watch with no bespoke server left in either family.
