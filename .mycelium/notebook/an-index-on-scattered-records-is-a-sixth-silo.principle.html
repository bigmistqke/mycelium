A queryable index on top of scattered records is a sixth silo, not a fix design-history Commit messages, issues, design specs and ADRs, documentation, tests: each already exists to capture some piece of intent, and none of them stay connected to the code or to each other. A database on top of that (deciduous's SQLite store, an earlier graph-data.json export) gives back some queryability, but becomes one more thing that can drift from what it is supposed to describe. It fixes fragmentation by adding another fragment.
