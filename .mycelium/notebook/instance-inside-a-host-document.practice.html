A figure is the first instance that lives inside another document rather than being one

Every family so far is one document per instance. A knowledge node is a file, a spec is a file, a language entry is a file. A figure sits inside a report that is not a figure.

So the embedded figure carries no data-conforms-to, and the validator never checks it against the template that declares it. The audit still runs, because it walks for figure-graph elements rather than for instances.

Declaring conformance would likely break the nothing-outside-the-type audit, which expects an instance to keep its content inside its declared type. A report is mostly prose around the figure.

That is the open design question this spike found. Either the vocabulary of conformance grows a notion of an instance inside a host, or a figure stays unvalidated markup that only an audit sees.
