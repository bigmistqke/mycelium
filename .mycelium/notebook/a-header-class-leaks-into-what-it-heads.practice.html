A header lands on the container, and the code inside it shouts notebook

The pane grew section headers, and one of them unfolds a script. Giving that disclosure the header class put the styling on the container rather than on the word, so text-transform: uppercase inherited straight into the code. Every identifier in the script rendered in capitals.

The mistake is easy to repeat, because a header's styling is exactly the styling that must not inherit. A header uppercases, tracks its letters out, and shrinks — all of which a container passes to its children, and none of which survives contact with a code listing.

So a class naming a section belongs on the text that names it, never on what it heads. The fix separated the two selectors, and the summary carries the styling while the disclosure carries only the spacing.

A screenshot caught this in one glance and no check would have. The page renders, the audits pass, and the drawing has no layout to measure under happy-dom — the failure existed only as pixels.
