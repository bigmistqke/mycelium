Nothing makes an agent call a command. The harness offers the inverse instead, and the inverse sits in a better place: a hook running before a tool call can refuse it and hand the model a reason, so a shortcut fails with the name of the command that would have worked. Forcing the right call is unavailable, and blocking the wrong one arrives at the moment somebody makes it.

This project already ran the other experiment and has the result. A hook prints every family, every command and every audit at session start, and an agent went through that wall, then searched the corpus with a directory listing and stripped the markup by hand. Upfront documentation competes with the task and loses, which is the finding the entry on what killed earlier rationale systems already carries as the most-cited thing here.

The followup family solved the same problem and solved it well. Its --at is required, so an item waits in front of whoever next opens that file and nobody reads a list to find it. A hook before a tool call is --at pointed at an action rather than a file.

Scope decides whether this helps or hurts. A refusal covering every read of the corpus teaches an agent to route around it through a language the matcher cannot see, and nobody consults a gate that fails routinely.
