The open data-rel vocabulary an early design proposed closed to a fixed eight-label enum design-history The original proposal minted a data-rel value as a project needed it, the same way HTML's own rel attribute, microformats and schema.org resolved this tension for the web at large — verifies, supersedes, benchmarks, contradicts, whatever fit. It did not stay that way: depends_on, blocks, supports, contradicts, alternative_to, leads_to, specifies and elaborates are now the whole list, held as a pattern on the anchor each type declares, and validate rejects a ninth rather than accepting it.
