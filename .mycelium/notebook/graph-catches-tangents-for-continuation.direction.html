The graph's job includes catching tangents, not just decisions

User's framing, and it reorients the trigger question. A knowledge graph exists partly so an exploration can go sideways, find something valuable, and not lose it — the value is in continuation, being able to pick a thread back up in a later session.

That names a category the harness had no way to catch. The 15-minute timer fires on elapsed time; a commit hook fires on a diff. A tangent that produces prior art, a refutation, or a reframe produces neither, so the mechanisms in place could only ever have recorded the code-shaped subset.

It also reframes the cost argument. Capture is cheap precisely while still inside the tangent — the context is loaded, the sources are open. An hour later it costs a re-derivation, and a week later the thread has vanished. So the trigger is not an event a hook can observe; it is a moment, and the design question is how to make capture cheap enough at that moment that it happens by default.
