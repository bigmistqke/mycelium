deciduous's git-native cousin hive faked per-type shape onto one flat table with nodeTypeSupportsStatus() design-history deciduous specified six node types: goal, decision, option, action, outcome, observation. Of those, status only makes sense for goal, decision and action. hive, deciduous's git-native cousin, discovered this mid-build and had to bolt on a nodeTypeSupportsStatus() helper to fake per-type shape onto one flat SQL table. A per-type template makes this a non-problem: a goal template declares a status field, an observation template simply doesn't.
