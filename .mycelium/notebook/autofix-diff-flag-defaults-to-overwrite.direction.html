Autofix apply mode: a --diff/--dry-run flag, defaulting to overwriting the file in place

Two options sat open on how autofix should apply a fix: write it in place by default and offer --diff to preview first, or the reverse. The apply-mode option won, matching the convention every other command in this project already follows — writing in place with no confirmation step.

autofix now applies a fix once it passes the violated rule's own check, and --diff prints the proposed rewrite instead of writing it. A separate question stayed open rather than folding into this one: whether a fix inside a corpus document should route through that family's own update command rather than writing the file directly.
