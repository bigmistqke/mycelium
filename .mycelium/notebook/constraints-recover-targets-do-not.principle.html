A history yields the constraints a codebase obeys and never the target it aimed at

Every one of the six principles the repl report states is a constraint. The caller supplies the compiler, the library owns no file system, and behaviour arrives as data. Each one says what the code may not do.

Not one of them is a goal. The artefacts show a library shedding responsibility for two years and never say what it was trying to become, so the convergence only reads as convergence from the end.

This sharpens the claim that derivation recovers mechanism and misses intent. The missing tier is not vague context, it is the objective.

A constraint leaves a mark in the code, because code that violates it fails. A target leaves no mark at all once the code reaches it.

So a derived graph can hold a complete bottom layer and still have no root. That is a structural gap rather than a coverage gap, and reading harder will not close it.
