Parsers are an acceptable dependency here — replace the JSDoc --help regex with acorn

The command line's own --help read a script for its doc comments with a regular expression matching export function name literally. An async command or an arrow-function export lost its --help text with no error, silently — nothing said the flag had gone missing, since a regex has no way to notice what it never matched.

The fix swaps the regex for a real parse with acorn: walk the script's top-level exports and match each one to its nearest preceding block comment by source position, rather than by one fixed text shape. A parser reading structure catches every export, where a hand-written pattern needs somebody to name each new shape one at a time.
