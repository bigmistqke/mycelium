None of the three touched the template. canon.template.html declared no such child, so the closed-field check would have rejected one, and no command could write it. Zero axioms carried a reference and nothing said so, because there was no gap for a check to find: an absent optional field looks exactly like a field nobody has filled yet.

Three documents agreeing is what made this hard to see. A design doc says what should be, and reads the same either way. A precedent citation is the worse one, since it argues from the thing rather than describing it, and an argument from something that does not exist still sounds like an argument.

The number gave it away rather than the prose. The spec counted seventeen ungrounded axioms; the corpus holds fifteen. A count written into prose cannot notice that it counted the wrong thing, which is the same failure as a figure nothing can re-run.
