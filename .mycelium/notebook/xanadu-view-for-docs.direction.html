A design conversation explored a different way to browse a documentation directory: instead of laying every document out as an abstract diagram, open the real documents side by side and draw visible lines between the specific links that connect them — the way Ted Nelson's Xanadu project displayed connections between documents rather than between abstract boxes.

The discussion settled several pieces: isolating each opened document visually with the browser's shadow DOM rather than an iframe, so a script can measure exactly where a link sits and draw a connector to it; keeping each document's doctype and character encoding while dropping its html, head and body tags, since a browser reconstructs those automatically; and where the tool's own code should live — a new file under a commands folder, since the engine stays small and this tool would carry a lot of presentation logic despite reading generic data.

 led to favoring a canvas of real panels over a precomputed graph diagram
