Rename the graph-* tag family to knowledge-*

Imported from the project’s earlier decision log, frozen 2026-07-23.

"graph" only names the shape of the six node types, and most of this project is graph-shaped already — every document links to others — so it does not distinguish these six types from anything else.

"knowledge" names what they actually are: captured reasoning, not structure for its own sake. It also matches the word the project's own title already uses, "v4: A Knowledge Graph as Hypermedia".

Renamed consistently across the tag prefix, the not-yet-built template file (knowledge.template.html and knowledge.template.css), the instance directory (knowledge/), and the audit script — keeping prefix and directory in sync the same way graph-* had originally been justified by mirroring a graph/ directory.

 the family prefix had to name what the types are, not their shape
