The Claude Code team argues HTML beats Markdown for AI-generated documents html-as-interface

This is the article that inspired treating HTML as the corpus's canonical store rather than a stack of Markdown files. The Claude Code team argues that Markdown flattens output into a report a reader skims once and abandons, while a self-contained HTML file becomes an interface: it can hold tables, CSS, SVG and interactive controls in one document, and a reader stays in the loop with the reasoning instead of passively accepting it.

The five use cases the article names — specs and planning, code review, design prototypes, research reports, custom editing interfaces — line up with what this project's own templates now do: notebook.template.html, canon.template.html, spec.template.html and figure.template.html each turn one of those into a document a reader can open rather than a section in a longer file.

Source: Using Claude Code: The Unreasonable Effectiveness of HTML.
