An axiom declares the region it governs, and that region inherits it

An axiom declares what it governs, and everything inside that region inherits it. A specification for one subsystem then collects every axiom whose region contains it, without anybody linking the two.

This answers the question refinement leaves open. Every general axiom reaches every subsystem automatically, so does this subsystem honour that axiom always has a target to check against.

It also introduces a second vocabulary beside the links: a set of region names, applied to each axiom by hand. Link, do not tag refused exactly that for topics, on the grounds that a name applied by judgement drifts and a link does not. A region is more structural than a topic, so the refusal is not automatic, but it is the same shape and it deserves the same argument.
