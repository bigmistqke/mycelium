A document conforms by reference to one specific template, never by declaring an abstract global type name design-history A document does not declare 'I am a claim' as an abstract type. It links to one specific template, addressed the way HTML has always addressed a piece of a document: a path and a fragment. Two different documents can each declare their own shape under the same coincidental label and never conflict, because nothing ties them together except that label — the same way two sites can both use schema.org/Person a little differently. There is no global type registry to keep consistent, because there is no global namespace to begin with.
