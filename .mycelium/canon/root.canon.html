A document is the source of truth, and the tooling reads it.

Everything the tooling knows sits in a document somebody can open. A template declares a type, a command lives inside the template it serves, a check rides along with the vocabulary it checks, and the command line finds all of it by crawling rather than by holding a list.

The alternative is a program that knows the shapes and a pile of files that merely hold data. That splits every claim in two, and the copy in the program is the one nobody reading the corpus can see.

This is why a node may only refer to what a reader can open. A number in a deleted database and a fact recoverable only from git history both fail the same test.
