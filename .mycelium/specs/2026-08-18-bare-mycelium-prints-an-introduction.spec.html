Bare mycelium and --help both print an enriched roster approved 2026-08-18

Bare mycelium and mycelium --help used to print the same thing: every family, every command, every audit, with no purpose and no sense of how much of the corpus lived where. That page grew across this session from roughly six thousand to over ten thousand characters as five families gained commands.

A first attempt split the two. Bare mycelium would print a short line per family — its purpose and how many documents conformed to it — on the theory that a bare invocation asks for nothing in particular, so a wall of every command answers a question nobody posed. Direct feedback overturned that: a session meeting the corpus for the first time needs more information at that moment, not less, since it has nothing yet to ask a narrower question about. Shortening the one screen a new session gets traded completeness for brevity at exactly the point completeness mattered most.

Bare mycelium and --help print the same thing again, and that thing now carries what the short-lived split version had plus what the original roster had. Nothing is removed to make room: a host's line carries its id, how many documents conform to it, its file, its declared purpose, and every command it exports with that command's own summary — all four in one place instead of split across two commands.

The opening line is the corpus's own first root axiom, read fresh rather than repeated here a second time. A host's purpose comes from the template-host it now declares. A count comes from walking data-conforms-to the same way explore list already does — nothing here names a family, so a twelfth one counts and lists itself without an edit.

Sorted alphabetically, the way the roster always was, since this is now a reference a reader scans by name rather than a first impression read once top to bottom. A host with no commands still gets a purpose line, since a family that authors nothing by command — figure, whose author writes nodes and edges straight into the document that draws them — is a fact worth stating rather than a reason to disappear from the listing.

The purpose is not shortened. A followup already states why: a title that gets truncated is a title whose length limit failed at its one job, so a host's line is as wide as its purpose needs.

No new command name. mycelium about was considered and dropped for the same reason across both versions of this design: an agent's reflex is the bare name or --help, never a command it has to already know exists.

mycelium <family> with no verb still prints that one family's own commands in full, unchanged by this.
