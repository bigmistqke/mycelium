Commands: page

a shared home for generating and serving a page, so a family declares what it draws instead of hand-rolling its own output and watch server page.command.html: a shared home for generating and serving a page
Not a template: like explore.command.html, this file declares no <template id="…"> and nothing conforms to it via data-conforms-to.
A family opts in by exporting page: export const page = { index(): string { ... } }, the same nested-object shape a command table already uses. Nothing here executes unless a family declares one.

Commands

A page's own leaf is a pure function from corpus state to an HTML string — it knows nothing about paths, flags, or serving. Everything below is what turns that string into a file at page/<family>/<verb path>.html, or into a response an open browser tab can reload.
