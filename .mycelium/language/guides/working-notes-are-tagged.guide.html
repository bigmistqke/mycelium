A note to yourself while writing code is worth having. It holds what you have not settled yet, and deleting it to keep the file tidy loses the thing you were about to come back to.

It stops being worth having the moment the work lands. Nobody reading the file later can tell an unresolved question from a description of how the code works, so an untagged note reads as documentation and outlives its usefulness.

Open one with WIP:. The tag says which kind of comment it is, and says it in a form both a reader and a command can see.

The comments command cuts a tagged note without asking a model, since the tag already carries the verdict. So this guide is the convention, and that command is what happens when someone forgets it.
