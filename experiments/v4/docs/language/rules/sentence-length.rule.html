Keep a sentence under forty words.

The roster reads the command scripts, so it cannot drift.

The roster is read off the command scripts themselves rather than maintained by hand in a separate file somewhere else in the repository, which is the whole reason it cannot drift from what the tool actually exports, and also why nobody has to remember to update it.

Forty, not the twenty-five ASD-STE100 uses. ASD-STE100 chose that number for aircraft maintenance procedures read by non-native speakers; this corpus is expository prose about software, where the median sentence is fifteen words and a cap of twenty-five would flag a quarter of everything written.
