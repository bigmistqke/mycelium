49 instances retagged and moved, the template and its stylesheet renamed, every type and field prefix changed, the audit renamed, and the command becomes mycelium run language. validate could not have caught the one real bug. The list command reads fs.list('dictionary'), which after the move named a directory that no longer existed, so it returned nothing and said so cheerfully. Nothing runs commands during validation. It showed up because the count was checked before and after, not because anything failed.

The spec named for the family was renamed too, and its four referrers repointed. A specification is a living document about a current thing, so a name that no longer matches is worse than a changed address, and every referrer is inside this repository. We left node filenames alone on the opposite reasoning: a node is a dated record of something that happened, and its slug describes what occurred at the time.

We split prose by use and mention, the same rule that decided the earlier migrations. Text naming the family became language. Text using the ordinary word did not: ASD-STE100's own dictionary is still a dictionary, and a dictionary that only defines approved words prevents nothing is a claim about dictionaries.
