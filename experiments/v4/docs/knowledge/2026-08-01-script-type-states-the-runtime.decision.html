The script type states the runtime, and the load hook reads it per script 88 active

A script's type already did three jobs: an unrecognized value stops a browser running the tag, the tag keeps its raw-text parsing, and the value is the discovery selector. It takes a fourth. mycelium/* means Node only, so TypeScript is allowed; module and classic mean a browser, so the content stays JavaScript.

Node does not guess. A load hook returning format: "module" for a source carrying a type annotation fails with SyntaxError: Unexpected token ':', and returning format: "module-typescript" runs it. Both were tried before this was written.

The hook therefore reads each script's own type rather than applying one format to everything it serves. That is not tidiness. The hook is not reserved to mycelium/*: knowledge.template.html line 605 is a type="module" script with id="extract-graph" that has to stay valid in a browser, and the command block imports it through this same hook at line 649. One format for everything would tell Node that a browser-facing script may contain TypeScript.
