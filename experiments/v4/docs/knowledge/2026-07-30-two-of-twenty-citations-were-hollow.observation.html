Two of twenty citations pointed at the wrong node, and one error propagated 95

Computing the import closure meant reading every deciduous node the v4 graph cites. Twenty distinct citations; two were wrong, both in declare-belonging-derive-liveness.decision.html:

  • "What deciduous #5 calls the missing retirement concept" — #5 is "Hybrid — Rust core with TS interface", an option about implementation language. The retirement concept is #310.
  • "#325: Composition makes decision status DERIVED, not declared" — #325 is "ONE LADDER", about v2's gradient and v3's waist being the same structure. The quoted sentence is verbatim #311.

Both claims were sound; only the pointers were wrong. That is what makes this the expensive kind. A dangling citation to a node that does not exist is caught by any link checker. A citation to a real node that does not support the claim reads as fine and survives every structural check — exactly the case that node argues needs mutation testing or blind re-derivation. It was found by blind re-derivation: reading the target and asking whether it says what the citing node claims.

The error propagated. Two later nodes inherited it without re-checking. option-retired-status-enum repeated "#5 says is missing". link-do-not-tag, written hours ago, said the decision "cites #325 and #364" — describing the wrong pointer rather than the source. A citation copied from a citing node rather than from the source carries the original error forward and adds a witness for it.

Rate, with the caveat that it is one sample. 2 of 20 is 10%, and both sit in one node written in a single burst, so this is not evidence about citation accuracy in general — it is evidence that unverified citations in this graph are wrong at a rate above zero, which was previously unmeasured and assumed to be zero. The same discipline that produced the 52% caveat applies here: do not promote this number.

What it argues for. The import is the first thing that ever forced every citation to be resolved, and it found these immediately. That is a reason to finish it rather than a reason to be careful about it: a citation pointing into a corpus the graph cannot reach is a claim nobody can check.
