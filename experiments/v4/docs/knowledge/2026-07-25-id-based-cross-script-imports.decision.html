Address cross-script imports with the same #id fragment convention as data-rel 70 pending narrows the addressing scheme for the virtual modules this decision introduces

Not reverse-DNS-style names, and not random UUIDs — the #id fragment convention already carries data-rel and data-conforms-to, so cross-script-block imports reuse it rather than introducing a third addressing scheme.

Two consequences that make the scheme total:

  • A script with no id is simply not importable. Absence of an address is the opt-out; nothing needs to be declared to stay private.
  • A loader's internal identity for an unlabeled script is derived deterministically from its file and position, never assigned randomly — so the same input always produces the same identity.
