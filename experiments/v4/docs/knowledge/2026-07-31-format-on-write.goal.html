Two files picked up a whole-file reindentation from adjacent work: closing tags moved onto their own lines, one attribute list wrapped. 1136 changed lines across the two, of which 36 were substantive and every one of those was layout. Nothing was written and nothing was lost.

The cost is that such a diff is unreviewable and it lands in whoever commits next. It swept into a commit here and had to be taken back out, because the commit message described four files and the commit held six.

The cause is that no formatting happens on write. Every path that writes a document produces whatever layout its author or its serializer happened to produce, so two writers disagree about a file that neither of them changed. commit() already normalises whitespace and reindents the children of a conforming element, which is the same job started and left half done: it settles the fields and leaves the prose around them to drift.

What this needs is one formatter, applied by whatever writes a file, so that layout stops being a property of who last touched a document. Deferred rather than done, because it touches every write path and would be a poor thing to change in the middle of other work.
