The cost argument. Reading is O(agents × files) — fifty small agents each re-deriving the same comprehension and throwing it away. A graph is a cache of comprehension: pay O(files) once, query N times.

The resolution of context bloat. You do not render a database into a prompt; you give the agent a query interface. That is v0's decision #20, written in January for the package everyone had since written off as the abandoned first exploration.

The reversal. v0 was never the wrong direction — it is the foundation, built first and mistaken for a false start.
